**Os comandos a seguir, são uns dos trintas comandos essencial no Linux:**


## Comando: `CD`
**O que ele faz?**

Permite navegar entre diretórios do sistema.

**Exemplo:**
```bash
cd /Home/Usuário
```

## Comando: `PWD`
**O que ele faz?**

Exibe o caminho completo do diretório atual.

**Exemplo:**
```bash

Pwd
```

## Comando: `MKDIR`
**O que ele faz?**

Cria novas pastas

**Exemplo:**
```bash

Mkdir dados_exeperimento
```

## Comando: `RM`
**O que ele faz?**

Remove os arquivos ou diretório do sistema.

**Exemplo:**
```bash

Rm arquivo.txt
```

## Comando: `CP`
**O que ele faz?**

Copia arquivos ou diretório de um local para outro.

**Exemplo:**
```bash

Cp dados.txt backup dados.txt
```

## Comando: `MV`
**O que ele faz?**

Move ou renomeia arquivos e diretórios.

**Exemplo:**
```bash

Mv dados.txt /Home/Usuario
```

## Comando: `TOUCH`
**O que ele faz?**

Cria arquivos vazios ou atualiza a data de modificação.

**Exemplo:**
```bash

Touch novo arquivo.txt
```

## Comando: `CAT`
**O que ele faz?**

Exibe o conteúdo de arquivos no terminal.

**Exemplo:**
```bash

Cat resultados.txt
```

## Comando: `NANO`
**O que ele faz?**

Editor de texto simples no terminal.

**Exemplo:**
```bash

Nano script.sh
```

## Comando: `CLEAR`
**O que ele faz?**

Limpa o terminal.

**Exemplo:**
```bash

Clear
```

## Comando: `HISTORY`
**O que ele faz?**

Mostra o histórico de comandos utilizados.

**Exemplo:**
```bash

History
```

## Comando: `CHMOD`
**O que ele faz?**

Altera permissões de acesso de arquivos e diretórios.

**Exemplo:**
```bash

Chmod 755 script.sh
```

## Comando: `GREP`
**O que ele faz?**

Busca padrões de texto dentro de arquivos.

**Exemplo:**
```bash

Grep "erro" log.txt
```

## Comando: `FIND`
**O que ele faz?**

Localiza arquivos e diretórios no sistema.

**Exemplo:**
```bash

Find . -name arquivo.txt
```
## Comando: `TAIL`
**O que ele faz?**

Mostra as últimas linhas de um arquivo.

**Exemplo:**
```bash

Tail arquivo.txt
```
